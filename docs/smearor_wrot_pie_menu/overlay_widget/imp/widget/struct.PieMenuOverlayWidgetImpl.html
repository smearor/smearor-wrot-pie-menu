§visible: Arc<AtomicBool>

Whether the pie menu is visible. This is used to determine to draw the pie menu or not. If this is true, the pie menu will be drawn. If this is false, the child widget will be drawn.

§overlay: Overlay§pie_menu_widget: RefCell<Option<PieMenuWidget>>§is_zooming: Arc<AtomicBool>§message_sender: RefCell<Option<Sender<PieMenuMessage>>>

Message sender for communicating with main application

§initial_rotation: RefCell<Option<f32>>

Initial rotation when rotation gesture starts

§is_rotating: Arc<AtomicBool>

Whether rotation gesture is active

§last_sent_rotation: RefCell<Option<f32>>

Last rotation value sent to main application

§activation_threshold: AtomicF64

Pinch-to-zoom scale threshold above which the pie menu opens. Configurable via set_activation_threshold(). Default: 3.5.

§deactivation_threshold: AtomicF64

Pinch-out scale threshold below which the pie menu closes. Configurable via set_deactivation_threshold(). Default: 0.5.

§rotation_gesture_enabled: AtomicBool

Whether the rotation gesture is active when the pie menu is open. Default: true.

§rotate_gesture: RefCell<Option<GestureRotate>>

Reference to the rotate gesture controller for propagation phase toggling.

§scroll_rotation_step: AtomicF64

Scroll rotation sensitivity multiplier. Default: 5.0. The rotation delta is computed as dy * sensitivity.

§left_stick_x: Cell<f32>

Latest left stick X-axis value in [-1.0, 1.0]. Updated by handle_left_stick_x, consumed by the tick callback. A value of 0.0 (or within deadzone) stops continuous rotation.

Thread safety: Cell is !Sync. This is safe because all writes occur on the GTK main thread via glib::idle_add_local. The SDL2/evdev polling thread must not write to this field directly.

§key_controller: RefCell<Option<EventControllerKey>>

Key controller attached to the root window for global keyboard shortcuts. Created in root(), removed in unroot().

§submenu_stack: RefCell<Vec<String>>

Stack of opened submenu item ids. Empty means main ring is active.

§submenu_radii: RefCell<HashMap<u32, f32>>

Per-level submenu radius overrides. Level 0 is the main ring. Levels without an explicit override use main_radius + level * step.

§submenu_radius_step: AtomicF64

Step width between consecutive ring levels. Default: 80.0.

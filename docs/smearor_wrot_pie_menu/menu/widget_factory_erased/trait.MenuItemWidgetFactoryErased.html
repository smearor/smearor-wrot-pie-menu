Expand description

Type-erased factory trait for registry storage.

This trait allows the registry to store factories with different Config types in a single HashMap<String, Box<dyn MenuItemWidgetFactoryErased>>.

A blanket implementation automatically converts any MenuItemWidgetFactory into a MenuItemWidgetFactoryErased by deserializing item.widget_config into the factory’s Config type.

Whether inner and outer ring markings are drawn. Default: true.

§keyboard_selection: RefCell<Option<String>>

ID of the currently keyboard-selected item, if any. Stored as a string ID (not an index) to remain stable across DashMap insertion/removal order changes.

§submenu_stack: RefCell<Vec<String>>

Stack of opened submenu item ids. Empty means main ring is active. Synced from PieMenuOverlayWidgetImpl via set_submenu_stack.

§submenu_radius_step: AtomicF32

Step width between consecutive ring levels in pixels.

§widget_registry: RefCell<MenuItemWidgetRegistry>

Widget registry resolving type names to factories. Pre-populated with standard implementations ("circle", "square").

§item_widgets: RefCell<HashMap<String, Widget>>

Cached item widgets keyed by item ID. Widgets are built once, registered as children of PieMenuWidget via set_parent, and positioned during the GTK4 layout phase in WidgetImpl::size_allocate.

pub(crate) fn ensure_item_widgets(&self)

Builds widgets for all menu items that don’t have a cached widget yet.

This is called during the snapshot pass. Widgets are built once, registered as children of PieMenuWidget via set_parent, and stored in item_widgets. Subsequent renders reuse the cache.

Widgets for items on the active ring are made visible; all others are hidden.

Source

pub(crate) fn clear_item_widgets(&self)

Unparents and removes all cached item widgets.

Called by refresh_widgets to force a full rebuild on the next layout pass. Mutations are deferred to the next event loop iteration via glib::idle_add_local_once by the caller to prevent RefCell reentrancy panics.

Source

pub(crate) fn remove_item_widget(&self, id: &str)

Unparents and removes the cached widget for a single item.

Called by set_widget_config to force a rebuild of a single item’s widget on the next layout pass.

Source

fn compute_next_selection(&self, direction: i32) -> Option<String>

Computes the next selection ID when cycling by direction (-1 for CCW, +1 for CW). Skips disabled items. Returns None if the menu has no enabled items. Does not mutate state or trigger redraw.

Source

fn compute_first_selection(&self) -> Option<String>

Computes the first enabled item ID (smallest angle). Returns None if the menu has no enabled items. Does not mutate state or trigger redraw.

Source

pub(crate) fn cycle_selection(&self, direction: i32)

Cycles the keyboard selection by direction (-1 for CCW, +1 for CW). Items are sorted by angle to ensure deterministic navigation order.

Source

pub(crate) fn select_first_item(&self)

Selects the first item (smallest angle, typically 0°).

Source

pub(crate) fn find_nearest_item(&self, target_angle: f32) -> Option<String>

Finds the enabled menu item whose angle is closest to target_angle (in degrees). Returns the item ID, or None if the menu has no enabled items.

Source

pub(crate) fn set_keyboard_selection(&self, id: String)

Returns whether the item with the given ID is the current keyboard selection.

Source

pub(crate) fn set_submenu_stack(&self, stack: Vec<String>)

Sets the submenu navigation stack and triggers a redraw. An empty stack means the main ring is active.

Source

pub(crate) fn submenu_depth(&self) -> u32

Returns the current submenu depth (0 = main ring).

Source

pub(crate) fn active_ring_items(&self) -> Vec<MenuItem>

Returns the items of the currently active ring. When no submenu is open, returns top-level items. When a submenu is open, returns the items of the innermost open submenu.
